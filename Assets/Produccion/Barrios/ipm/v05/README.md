# Taller del IPM · interior y combate · v05

Escenario interior basado en las fotos reales del taller escolar: tornos y máquinas al lateral, bancos de trabajo, armarios azules, columnas de acero y líneas amarillas de seguridad. El fondo de combate deja libres las zonas de despliegue y conserva las plataformas de batalla.
