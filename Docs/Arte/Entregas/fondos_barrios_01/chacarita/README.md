# Chacarita · fondo de combate

Fondo de combate de 256×192 px en pixel art, con una escena reconocible del barrio y dos plataformas verdes en los puntos de apoyo de la escena actual. No incluye Pokémon ni interfaz. Pórtico, galerías y mausoleos; representación ficticia y respetuosa.

- Asset PNG: [fondo_batalla.png](../../../../../Assets/Produccion/Barrios/chacarita/v01/fondo_batalla.png).
- Fuente editable: [chacarita_fondo_batalla.svg](../../../../../ArteFuente/Batalla/chacarita_fondo_batalla.svg).
- [Preview 1×](fondo_batalla_1x.png) · [preview 4× nearest](fondo_batalla_4x.png) · [paleta](paleta.json).

**Estado: versión v01 reemplazada visualmente por v02; se conserva como historial.** El formato respeta el fondo actual de combate (256×192). Las plataformas coinciden con los apoyos existentes en `(190,90)` y `(64,174)`; al usar un fondo personalizado, el juego oculta sus plataformas base. No se modificaron escenas ni scripts. La validación confirma dimensiones, PNG opaco y previsualización nearest; todavía no hay captura del motor.
