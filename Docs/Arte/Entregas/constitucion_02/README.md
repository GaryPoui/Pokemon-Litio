# Constitución · fachada de estación v02

Fachada modular pixel art de 192×96 px inspirada en el pabellón histórico de Plaza Constitución. Tiene reloj, alas laterales, mansardas, pilastras y marquesina de hierro; la pieza está dibujada para el juego y no pretende copiar la estación con exactitud.

**Estado: asset final pendiente de integración.** Se verificaron lienzo, transparencia, lectura de reloj y ventanas, y vista nearest. No se colocó en una escena; no hay prueba del motor.

Referencia de identidad: [Estación Plaza Constitución, Argentina.gob.ar](https://www.argentina.gob.ar/capital-humano/cultura/monumentos/estacion-plaza-constitucion). La referencia orienta el pabellón y el lenguaje ferroviario; las formas pixel art son originales.
