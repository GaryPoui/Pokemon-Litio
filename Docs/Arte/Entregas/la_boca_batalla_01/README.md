# La Boca · fondo de combate

Fondo de combate de 256×192 px en pixel art, con una escena reconocible del barrio y dos plataformas verdes en los puntos de apoyo de la escena actual. No incluye Pokémon ni interfaz. Conventillos y puerto del Riachuelo; adoquín reutilizado de calibración 01.

**Estado: asset final pendiente de integración.** El formato respeta el fondo actual de combate (256×192).
