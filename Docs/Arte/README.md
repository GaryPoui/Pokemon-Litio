# Arte de Pokémon Litio

La región toma barrios y lugares de Buenos Aires como base para sus ciudades. El objetivo visual es conservar la escala y la claridad de los Pokémon de Nintendo DS, con arquitectura y personajes que se reconozcan como porteños.

| Documento | Contenido |
|---|---|
| [Barrios](barrios.md) | Identidad, lugares de referencia y piezas de cada ciudad |
| [Guía visual](guia_visual.md) | Perspectiva, paleta, escala y formatos del proyecto |
| [Producción](produccion.md) | Prioridades, entregas y revisión de assets |
| [Personajes y Pokémon](personajes.md) | Criterios para NPC, variantes y nuevas criaturas |
| [Referencias](referencias.md) | Fuentes de arquitectura, cultura y estética |

El primer trabajo es rehacer el entorno de La Boca. Los conventillos y el estadio actuales sirven para comprobar medidas y accesos; las láminas de concepto sirven para discutir ideas. Las piezas finales deben tener su propia escala, perspectiva y recortes, comprobados dentro de la composición del juego.

Estos documentos describen la dirección del arte. No implican que las ocho ciudades, sus interiores o sus gimnasios estén implementados. La base técnica se relevó en `c84c115f`; las medidas deben contrastarse con los recursos actuales antes de reemplazar una textura.
